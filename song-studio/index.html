MIDI 连接

PA700 用 USB DEVICE 接电脑/平板。浏览器请用 Chrome 或 Edge；GitHub Pages 是 HTTPS，本地测试用 localhost。

已授权过 MIDI 的浏览器，检测到一台 PA 会自动连接；检测到多台时会在弹窗里让你选择。

PA700 设置（重要）
  1. Global > MIDI > General Controls：MIDI Preset 用 Default，关闭 Local Control On。
  2. Global > MIDI > MIDI OUT Channels：把演奏通道设为 Play Tr 01（16 轨则 Ch1–Ch16 对应 Play Tr 01–16）；否则 SEQ 模式弹琴不会从 USB 发出来。
  3. 按 SEQUENCER，选空 Song；不要启动 PA700 自己的播放器/自动伴奏。
  4. 确认 MIDI Filters 没有过滤 Notes。

音色表

选中会发送 Bank/PC，并在当前轨试听 C4。支持 KORG Pa3X / Pa4X / Pa5X / Pa300–Pa1000 / KROME EX / KRONOS，以及 Yamaha MODX / MODX+ / MODX M / MONTAGE / MONTAGE M。

Yamaha 使用 Performance 列表（MSB 63 单声部）：琴上需 MIDI I/O Mode = Multi，Part 的 Program Change 接收开启；UTILITY → Settings → Advanced 里 Bank Select 和 Pgm Change 都要设为 On，否则只会换音色号、不换库（节拍器就不会变成鼓）。

网页内置音源的音色在：选中轨道 →「轨道」→「内置音源音色（网页合成）」。两者互不影响。

轨道设置 1

打开音色表，点音色会立即发送 Bank/PC 并试听 C4；轨道名/音量等仍点下面的「应用」保存。

与琴上同通道音量双向同步：琴上调会显示在这里，播放不覆盖琴上音量，点「应用」才发送。

只影响网页内置音源；琴上的音色仍由「音色」按钮决定。「自动」按轨道音色/通道映射。

整轨八度：把 ±12 直接写进这个通道在所有段落的 MIDI 音符（立即生效，可撤销）。

把这条轨道的琴上音色、内置音源音色和所有段落 Pattern 跟所选轨道对调；交换后立即把两条轨道的新音色发到琴（跟随 PA700 的轨道不发）；自定义轨道名会随内容一起换到另一轨，没改过名的保留 Track 序号；通道、音量、声像不变，撤销/重做也会把音色同步回琴。

录音 / 循环小节数

缩短长度会裁剪超出范围的音符，可撤销。

段落设置

默认名字按大写字母 A–Z 排；改成「主歌」「副歌」「Solo」等都可以，Pattern 页顶部和格子里会显示新名字。

新建歌曲

创建一个空白工作区：16 轨 × 8 个段落（A–H，之后可随时增加或改名），4 小节，120 BPM，所有轨道恢复默认名称、音色和音量。

当前工作区会被清空。已保存在「歌曲」里的歌曲不受影响；想保留当前内容，请先取消，在「歌曲」里点「保存当前」。

PA700 设置 / 限制

琴跟随 App：PA700 的 Global > MIDI > General Controls 里把 Clock Source 设为 External USB（接 USB 时先试它；若琴上 External MIDI / External USB 两个都有，也可以两个都试），并关闭 Clock Send。外部时钟下 PA700 面板的 Start/Stop 不可用，必须由 App 发 Start。若琴上一直显示 250，说明它没有收到或没有锁定 App 的时钟：确认上面两项、确认不在 Song Play 模式，再试「同时发 Start/Stop」或「发送 Start 测试」。

App 跟随琴：在 PA700 打开 Clock Send、Clock Source 保持 Internal；Clock Send 每次开机都会关闭，需要重新打开。PA700 只在 Style Play / Sequencer 模式接收外部时钟，Song Play 不支持。

两个方向只开一个：跟随琴 = Internal + Clock Send 开；琴跟随 App = External USB + Clock Send 关，避免两台设备互相跟。

琴上播放/暂停控制 App：PA700 打开 Clock Send（每次开机重置）后，Song Play 的 PLAY/STOP 键会发 MIDI Start/Stop。上面的「琴上播放/暂停控制 App」默认已勾选；按琴上播放会从 App 开头开始，琴上暂停（发 Stop）时 App 停在当前小节，再按琴上播放（发 Start/Continue）从原位置继续。若在「速度 / 同步」状态行看到「最近收到琴：Start」，说明琴的按键消息已经到 App。

琴上控制键学习：在 PA700 的 Style Play > Pads/Switches > Switch 页把 Switch 1/2 设为 FX CC12 Switch / FX CC13 Switch，并保存到 Keyboard Set（每个 Keyboard Set 单独保存）。点上面的「学习开始键 / 学习停止键」后按一下对应的开关；学好后按开始键播放、按停止键停止并回到开头。这两个键和 Song Play 的 Start/Stop 共用「琴上播放/暂停控制 App」总开关。

Track Select 不是 MIDI 消息：PA700 不会发送“当前轨道”，App 只能按输入通道跟随；App 选轨会发送该轨音色/CC，但不会移动琴上的轨选光标。
